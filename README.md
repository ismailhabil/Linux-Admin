# Linux-Administration
## Project Overview
* In this project, you will take on the role of a junior Linux system administrator for a small company. Your task is to set up and configure a Linux server to meet the company’s basic needs. This includes configuring networking, managing users and groups, installing essential services, and automating backups with a script. The goal is to demonstrate your understanding of fundamental Linux administration tasks.
